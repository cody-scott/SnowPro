## Snowflake Notebooks

- Interactive notebooks in Snowsight mixing **SQL, Python and Markdown** cells.
- Run on a **warehouse runtime** or a **container runtime** (Snowpark Container Services, supports GPUs and pip packages) — useful for ML.
- Integrate with Git; can be scheduled.

## Streamlit in Snowflake

- Build and host **Streamlit (Python) data apps** directly in Snowflake.
- Data never leaves Snowflake; access is governed by **RBAC** (apps are objects with privileges).
- Runs on a warehouse (or container runtime). Deploy from Snowsight or with `snow streamlit deploy`.

## Snowpark

- Developer libraries for **Python, Java and Scala**: a **DataFrame API** whose operations are **pushed down** and executed inside Snowflake as SQL (lazy evaluation — nothing runs until an action such as `collect()` or `show()`).
- Also lets you create **UDFs, UDTFs and stored procedures** in these languages.
- Python packages come from the built-in **Anaconda** channel (or uploaded/staged code).
- Memory-heavy Snowpark work → **Snowpark-optimized warehouse**.
- **Snowpark Container Services** runs containerized apps on **compute pools** (CPU/GPU).

## Snowflake Cortex (AI)

| Feature | What it is |
|---|---|
| **AI SQL functions** | LLM-powered functions callable from SQL, e.g. `AI_COMPLETE`, `AI_CLASSIFY`, `AI_FILTER`, `AI_AGG`, `AI_SENTIMENT`, `AI_EXTRACT`, `AI_TRANSLATE`, `SUMMARIZE`. Models run inside Snowflake, so data stays governed. Billed by tokens. |
| **Cortex Search** | Managed **hybrid (vector + keyword) search** service over text data; the retrieval building block for **RAG** chatbots and enterprise search. |
| **Cortex Analyst** | **Natural language → SQL** over structured data, guided by a **semantic model / semantic view** describing business terms. Exposed as a REST API (and used by Snowflake Intelligence). |
| **Cortex Agents** | Orchestrate across Cortex Search and Cortex Analyst plus tools. |

> **Exam tip:** Unstructured text Q&A / RAG → **Cortex Search**. "Business users ask questions of sales tables in plain English" → **Cortex Analyst**. Classify or summarize text in a SQL query → **AI SQL functions**.

## Snowflake ML

- **ML Functions** (SQL): `FORECAST`, `ANOMALY_DETECTION`, `TOP_INSIGHTS`, classification — no ML expertise required.
- **Snowflake Feature Store** — create, manage and serve ML features.
- **Model Registry** — log, version and serve models (stored as schema-level **model** objects); run inference in SQL or Python.
- **ML Jobs / container runtime** — distributed training with popular frameworks.
