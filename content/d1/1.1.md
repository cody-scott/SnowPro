## Three independent layers

Snowflake is a hybrid of shared-disk and shared-nothing designs: one central copy of data, many independent compute clusters.

| Layer | What it does | You pay for |
|---|---|---|
| **Cloud Services** | Authentication, access control, metadata, query parsing & optimization, transaction management, infrastructure management | Only the portion that exceeds **10% of daily warehouse compute** |
| **Compute (Query Processing)** | Virtual warehouses — MPP clusters that execute queries | Credits, per second (60 s minimum on each start/resume) |
| **Database Storage** | Data stored as compressed, columnar **micro-partitions** in cloud object storage; fully managed, not directly accessible | Average compressed TB per month |

Key consequences:

- **Storage and compute scale independently.** Add warehouses without copying data.
- **Warehouses don't compete.** Two warehouses querying the same table don't affect each other's performance.
- Metadata lives in Cloud Services, which is why things like `COUNT(*)`, `MIN/MAX` on a column and `SHOW` commands can run **without a warehouse**.
- The query optimizer lives in Cloud Services and uses micro-partition metadata for **pruning**.

## Editions

Each edition includes everything in the one below it.

| Edition | Adds (highlights to memorize) |
|---|---|
| **Standard** | Core platform, Time Travel up to **1 day**, 7-day Fail-safe, encryption everywhere, Secure Data Sharing, network policies, MFA |
| **Enterprise** | **Multi-cluster warehouses**, Time Travel up to **90 days**, materialized views, search optimization, query acceleration, column-level security (masking), row access policies, object tagging, periodic rekeying |
| **Business Critical** | **Tri-Secret Secure** (customer-managed key), **private connectivity** (AWS PrivateLink, Azure Private Link, GCP Private Service Connect), support for HIPAA / PCI DSS regulated data, **account failover/failback** (client redirect) |
| **Virtual Private Snowflake (VPS)** | Completely separate Snowflake environment, isolated from all other accounts (no shared metadata store or compute) |

> **Exam tip:** "Needs multi-cluster / 90-day Time Travel / masking" → Enterprise. "Needs PrivateLink / Tri-Secret Secure / HIPAA / failover" → Business Critical.

## Cloud & region

- An account lives in **one cloud provider (AWS, Azure, GCP) and one region**.
- Pricing (credit cost, storage cost) varies by edition, cloud and region.
- Multi-region / multi-cloud is done with **replication**, not by stretching one account.
