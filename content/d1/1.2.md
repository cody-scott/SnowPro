## Snowsight (web UI)

The primary browser interface. Know what you can do there:

- **Worksheets** — SQL and Python worksheets, with role/warehouse/database context per worksheet.
- **Notebooks** and **Streamlit in Snowflake** apps.
- **Dashboards** built from worksheet charts.
- **Query History** and **Query Profile** (the visual execution plan — key for Domain 4).
- **Admin** — warehouses, users & roles, cost management, resource monitors.
- **Data** — database explorer, Marketplace, data sharing / listings.
- **Monitoring** — copy history, task history, dynamic table graphs.

Classic Console is retired; Snowsight is the answer for "web interface" questions.

## Snowflake CLI (`snow`)

- Open-source command-line tool for **developer workflows**: run SQL, manage objects, and deploy **Streamlit apps, Native Apps, Snowpark** code, notebooks and **Snowpark Container Services**.
- Uses **connections** defined in `config.toml`.
- Examples: `snow sql -q "select 1"`, `snow streamlit deploy`, `snow app run`, `snow stage copy`.
- **SnowSQL** is the older SQL-only CLI client; Snowflake CLI is the recommended successor.

## IDE integrations

- **Snowflake extension for Visual Studio Code** — connect, browse objects, run SQL/Snowpark, view results and query history from inside VS Code.
- Workflows also integrate with **Git** (Git repository objects) and the CLI for CI/CD.

## Other ways to connect (overlaps Domain 3)

- **Drivers**: JDBC, ODBC, Python connector, Node.js, Go, .NET, PHP.
- **Snowpark** libraries (Python, Java, Scala).
- **SQL REST API**.
- Partner tools via **Partner Connect** (ETL, BI, ML tools with a pre-configured trial).

> **Exam tip:** "Deploy a Streamlit or Native App from a terminal / CI pipeline" → Snowflake CLI. "Visualize a query's execution plan" → Query Profile in Snowsight.
